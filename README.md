eCommerce Backend
Overview
This is a Spring Boot-based backend for an eCommerce platform, implementing authentication, authorization, and CRUD operations for shops and products. It follows the RSC architecture (Repository, Service, Controller) and provides RESTful APIs for seamless interaction.

Features
User Authentication & Authorization

Implemented using Spring Security & JWT
Registration with OTP verification via email
Secure login with JWT token-based authentication
Shop & Product Management

CRUD operations for shops and products
RESTful APIs for managing resources
Security & Data Management

Role-based access control
Data persistence using Hibernate & JPA
Project simplified with Lombok for boilerplate code reduction
Technologies Used
Spring Boot - Backend framework
Spring Security - Authentication & Authorization
JWT - Secure token-based authentication
Hibernate & JPA - ORM and database interaction
Lombok - Reduces boilerplate code
MySQL / PostgreSQL (or any preferred database)
Mail API - For OTP-based email verification
